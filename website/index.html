Keep your consumer. Add a Spring annotation or a Go wrapper. Redis holds the state; your application owns the business logic.

Understand the boundaries +

A crash after a side effect but before completion can repeat that effect. Lease expiry and Redis data loss can also allow reprocessing. Use business-level idempotency keys or a transactional inbox for critical writes. No automatic lease renewal is included.
